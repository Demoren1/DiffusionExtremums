# DiffusionExtremums

Scientific experiment project.

## Project Structure

| Directory          | Description                              |
|--------------------|------------------------------------------|
| `code/`            | Python scripts and modules               |
| `notebooks/`       | Jupyter notebooks                        |
| `data/raw/`        | Raw, immutable datasets                  |
| `data/processed/`  | Cleaned and processed datasets           |
| `results/`         | Experiment outputs (logs, metrics)       |
| `figures/`         | Generated plots and figures              |
| `tex/`             | LaTeX paper sources                      |
| `screenshots/`     | Screenshots for documentation            |
| `trash/`           | Scratch and temporary files              |

## Setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
